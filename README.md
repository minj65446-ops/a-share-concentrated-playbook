# A股集中式交易系统合集 · Concentrated Playbook

把「重仓少数标的」从一次押注，拆成一套可执行、可复盘的规则。

纯静态单页应用，**零依赖、无构建、无后端**，双击 `index.html` 即可运行。所有数据保存在浏览器本地，不上传任何服务器。

**在线体验**：https://minj65446-ops.github.io/a-share-concentrated-playbook/

---

## 模拟交易实验室

一个不联网的沙盘，用来练**动作是否合规**，而不是练选股：

- **三个场景**：趋势场 / 震荡场 / 退潮场，行情由确定性随机过程生成（可复现），非真实历史数据
- **交易约束**：T+1、100 股整数倍、佣金万 2.5（最低 5 元）、卖出印花税 0.05%、±10% 涨跌幅限制
- **自动风控**：下单时实时检测「未设止损 / 单票超限 / 单笔风险超预算 / 向下补仓 / 行业超限」，违规计入档案
- **止损自动执行**：每日推进时按 `min(止损价, 开盘价)` 撮合，跳空不给你侥幸的机会
- **实时指标**：总资产、累计收益、最大回撤、胜率、盈亏比、违规次数、净值曲线
- **赛博老师**：五关课程逐步解锁，根据你的实际操作状态给提示、讲解与体检报告

> 第 4 课的设计意图：**切到退潮场，什么都别买。** 空仓也是仓位。

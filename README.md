# A股交易学院 · A-Share Trading Academy

把「集中式交易」做成可以练的东西，而不是一篇读完就忘的长文。

**在线体验**：https://minj65446-ops.github.io/a-share-concentrated-playbook/

| 入口 | 说明 |
|---|---|
| `index.html` | **教学 App**（主入口）：学院 / 训练场 / 图谱 / 我的，移动优先 |
| `playbook.html` | **规则手册**：八套集中式策略完整版 + 风控引擎 + 模拟交易实验室 |

---

## 它和「一份文档」的区别

| 普通教程 | 这个项目 |
|---|---|
| 读一段策略说明 | 8 门课，每门配一道 K 线判题，答完才给解析 |
| 看文字讲买点 | 图上标 A/B/C 三个位置，点图上任意一个也能作答 |
| 文字讲「几成仓」 | 情绪周期四阶段滑块，仓位条实时变化，该做/不该做分栏对照 |
| 表格列止损规则 | 仓位计算器：改止损幅度，建议仓位立刻变 |
| 讲「不要违规」 | 模拟盘里下单即检测：未设止损 / 超配 / 补仓，全部记账 |

## 四个 Tab

**学院** — 学习路径 8 门课（核心卫星 → 仓位公式 → 止损三锚 → 趋势跟随 → 行业轮动 → 龙头聚焦 → 红利底仓 → 事件驱动）。每门课有「为什么 / 三个要点 / 常见死法」，完成后进度环点亮。

**训练场** — 六个 K 线情境题，覆盖：放量突破前高、高位放量长上影、跌破颈线、缩量阴跌、回踩均线不破、无量反弹到前高。每题三个选项，答错给完整解析。另有仓位计算器与模拟盘入口。

**图谱** — 情绪周期四阶段（冰点 / 启动 / 发酵 / 退潮），每阶段对应仓位区间、该做与不该做的事；下方是「策略 × 市况」横滑矩阵。

**我的** — 课程进度、判题正确率、错题数、四个成就徽章、每日盘后三问（按日期独立保存）。

## 多端

`miniprogram-uni/` 是 uni-app（Vue3）工程，一套代码编译到**微信小程序 / App / H5**。

| 端 | 位置 |
|---|---|
| Web | 根目录 `index.html` + `app.css` + `app.js` |
| 小程序 / App | `miniprogram-uni/`，`pages.json` 已配好 4 个 tabBar |
| 设计规范 | `docs/DESIGN.md`——设计令牌、组件映射表、三端差异清单 |

> 小程序工程为**同源骨架**，未在微信开发者工具中实际编译，`appid` 需自行填写。canvas 绘制逻辑与 Web 端不同（`uni.createCanvasContext`），已在 `common/kline.js` 中单独实现。

## 本地运行

```bash
git clone https://github.com/minj65446-ops/a-share-concentrated-playbook.git
cd a-share-concentrated-playbook
python -m http.server 8000
# 打开 http://localhost:8000
```

零依赖、零构建。所有进度存在浏览器 `localStorage`，不上传任何服务器。

## 数据说明

- 所有 K 线为**程序生成的合成数据**（固定随机种子，可复现），不映射任何真实股票
- 课程中的参数（止损幅度、仓位上限）是通用参考值，未针对任何具体市场环境校准
- 教学口径参考公开方法论：交易系统五支柱、集中投资的能力圈原则、芒格关于集中持仓的论述、情绪周期框架、行业轮动的因子构造

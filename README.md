把「集中式交易」做成可以练的东西，而不是一篇读完就忘的长文。

**在线体验**：https://minj65446-ops.github.io/a-share-concentrated-playbook/

| 入口 | 说明 |
|---|---|
| `index.html` | **教学 App**（主入口）：学院 / 训练场 / 图谱 / 老师 / 我的，移动优先 |

## 它和「一份文档」的区别

| 普通教程 | 这个项目 |
|---|---|
| 读一段策略说明 | 8 门课，每门配一道 K 线判题，答完才给解析 |
| 看文字讲买点 | 图上标 A/B/C 三个位置，点图上任意一个也能作答 |
| 文字讲「几成仓」 | 情绪周期四阶段滑块，仓位条实时变化，该做/不该做分栏对照 |
| 表格列止损规则 | 仓位计算器：改止损幅度，建议仓位立刻变 |
| 讲「不要违规」 | 模拟盘里下单即检测：未设止损 / 超配 / 补仓，全部记账 |
| 推荐「跟哪个老师学」 | 不列人名，列 8 个流派 + 4 类话术；每派都配「谁不该用」 |
| 从入门一路读到系统 | 五段路径，毕业标准全部从你的真实记录里算，没有「我觉得我懂了」 |

## 从小白到有系统（五段路径）

大多数教程的问题不是讲得浅，是**默认你已经知道股票是什么**——第一句就是「核心+卫星」「仓位 = 总资金 × 风险% ÷ 止损幅度%」。真小白缺的不是策略，是地基。

所以这个项目把顺序固定成三段：**先知道是什么（Lv1）→ 再学怎么做（8 门课）→ 最后找到适合你的那一派（自测 → 老师模块）**。

| 段位 | 名称 | 解决什么 | 毕业标准（可计算，无自评） |
|---|---|---|---|
| L1 | 启蒙 AWAKEN | 知道你买的到底是什么 | 13 条启蒙概念全部标记已读 |
| L2 | 筑基 DISCIPLINE | 把一次交易算清楚、执行完 | 前 3 门基础课 + 判题 ≥ 5 次且正确率 ≥ 60% |
| L3 | 寻道 EXPLORE | 找到适合你的那一派 | 完成流派自测 + 进阶课 ≥ 3 门 |
| L4 | 系统 SYSTEM | 把选股到复盘串成闭环 | 完成 8 门课 + 复盘 ≥ 7 天 |
| L5 | 化境 MASTERY | 知行合一 | 连续复盘 ≥ 7 天 + 判题最高连对 ≥ 10 |

**Lv1 启蒙层 13 条**不讲任何策略，只回答「你买的到底是什么」：
股票是什么 / 市盈率 / 市值 / K 线 / 成交量 / 均线 / T+1 / 涨跌停 / 手续费 / 股息 / 财报三张表 / 复亏比复利残酷 / 牛熊。
每条四个字段：一句话结论 → 为什么重要 → **常见误解** → 具体数字的例子。

**流派自测** 8 题，围绕三个硬约束：能投入多少时间、能承受多大回撤、本金规模。
其中若干选项是**陷阱项**（如「补仓摊低成本」「一亏就换策略」），选了不扣分，但会直接告诉你为什么八派全部反对——它的作用是教育，不是筛选。测完输出该派的约束条件，可一键跳到老师模块。

## 五个 Tab

**学院** — 当前段位卡 + 五段路径 + Lv1 启蒙 13 条 + 学习路径 8 门课（核心卫星 → 仓位公式 → 止损三锚 → 趋势跟随 → 行业轮动 → 龙头聚焦 → 红利底仓 → 事件驱动）+ 流派自测。每门课有「为什么 / 三个要点 / 常见死法」，完成后进度环点亮。

**训练场** — 六个 K 线情境题，覆盖：放量突破前高、高位放量长上影、跌破颈线、缩量阴跌、回踩均线不破、无量反弹到前高。每题三个选项，答错给完整解析。另有仓位计算器与模拟盘入口。

**图谱** — 情绪周期四阶段（冰点 / 启动 / 发酵 / 退潮），每阶段对应仓位区间、该做与不该做的事；下方是「策略 × 市况」横滑矩阵。

**老师** — 见下节。

**我的** — 课程进度、判题正确率、错题数、四个成就徽章、每日盘后三问（按日期独立保存）。

## 老师模块

网上教金融的人很多，但方法是有限的。这一页把「跟谁学」翻译成「学哪一派」：

**8 个流派**（主线龙头 / 趋势跟随 / 价值集中 / 行业轮动 / 量化多因子 / 红利低波 / 事件驱动 / 困境反转）

每张卡不是「粉丝数 + 视频数」，而是：

| 字段 | 含义 |
|---|---|
| 可核查程度 | 有公开业绩 / 方法可复核 / 无业绩披露（不是粉丝数） |
| 承诺 | 这一派主张能赚什么钱 |
| 教对了什么 | 这套方法真正有效的地方 |
| 教漏了什么 | 网上讲这套的人普遍**不讲**的那一半 |
| 识别陷阱 | 这一派最常见的自我欺骗方式 |
| 可执行核心规则 | 3 条，可直接照做 |
| 约束条件 | 最低资金 / 最大仓位 / 止损方式 / 交易频率 / 持仓数量 |
| **明确不适合的人** | 全页最有价值的一栏 |

**幻方**：按「你怎么赚钱」把八派分成四象限——择时派（攻·主动）、跟随派（攻·被动）、配置派（守·被动）、逆向派（守·主动）。点象限可定位。

**4 类反面样本**：晒单型、喊单型、内幕型、指标神型。斜纹底 + 灰头像区分，详情页只有「破绽」和「识别信号」，**不给可执行规则**——因为话术没有可执行内容。

**三问识人**：年化与最大回撤多少？什么行情下会连续亏钱？你靠什么赚钱？答不上来的，不必再听第二句。

**师承链**：格雷厄姆 → 护城河 → 集中持有；唐奇安通道 → 海龟 → A股动量 ETF；涨停板制度（1996）→ 情绪周期 → 主线龙头；Fama-French → 多因子 → 红利低波。方法都有来处，没有凭空出现的「独家战法」。

> 本页**不列任何真实人名**，也不评价任何具体账号。列的是流派——流派的方法可以被检验，个人业绩不能。

## 同步到 GitHub

正常情况是 `git push`，但某些网络环境下 git 的 HTTPS 传输会持续失败（`schannel: server closed abruptly` / `CONNECT tunnel failed 502`），而 REST API 正常。`tools/` 下两个脚本用于这种情况：

```bash
# 先看本地和远端差了多少（不上传，只读）
TOKEN=<token> node tools/check.js .

# 再上传
TOKEN=<token> node tools/upload.js . "commit message"
```

| 脚本 | 作用 |
|---|---|
| `tools/check.js` | 用 git blob sha1 算法比对本地文件与远端 tree，列出新增 / 变更 / 远端多出 |
| `tools/upload.js` | 用 contents API 逐文件提交（带 sha 更新，无 sha 新建） |

Token 需要 repo 写权限（fine-grained PAT 勾 `Contents: Read and write`）。只在 `upload.js` 的 `FILES` 列表内的文件会被同步。

## 数据说明

- 所有 K 线为**程序生成的合成数据**（固定随机种子，可复现），不映射任何真实股票
- 课程中的参数（止损幅度、仓位上限）是通用参考值，未针对任何具体市场环境校准
- 教学口径参考公开方法论：交易系统五支柱、集中投资的能力圈原则、芒格关于集中持仓的论述、情绪周期框架、行业轮动的因子构造
- 老师模块中「可核查程度」仅描述方法层面的可验证性，不代表任何具体个人的资质或业绩；页面不出现真实人名
